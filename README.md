# WubHub

WubHub is a React, Vite, and Capacitor app for PaymoneyWubby streams, VODs, community links, and mobile/TV viewing.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npx cap sync
```

## Android Debug APK

```sh
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```
